# Gate 2 tooling: fetch-log check, manifest, `gate2.sh`, CI workflow

**Why:** the Gate 2 window (02 §7, v0.7) runs to hour 2026-10-30T05Z. Everything §9 checks should be built and proven on the partial window now, so the run at the end is a single workflow dispatch.

**What:** standard library only; nothing imports either implementation.
- **`tools/fetch_log_check.py ROOT FIRST LAST`** (§8.4; §9 criteria 1 and 4):
  - every window hour has exactly one final outcome, and no logged hour has two
  - every file a final outcome names is archived with that SHA-256
  - every archived file is named by a row of its hour
  - It prints every problem, not just the first.
- **`tools/archive_input.py ... [MANIFEST]`** now also writes the `available_at` manifest: every final outcome with an `available_at`, in hour order. Missing hours aren't listed, so they use the backfill rule (§8). The reference's manifest therefore comes from neutral code, not the pipeline's exporter.
- **`tools/gate2.sh FETCHER_ROOT LIVE_OUT WORK_DIR`:** the same pattern as `gate1.sh`. It runs every check:
  - fixtures and fetch log
  - flat input + manifest
  - reference, compared to live
  - pipeline replay of the archive, compared to live (digest + R1–R7)
  - delay report
  - Then `tools/gate2_evidence.py` writes `evidence/gate2.json` (CI only): the gate1 fields plus the fetch log's SHA-256, the manifest and the delay report, with one entry per §9 criterion.
- **`tools/gate2_config.json`:** the window, and R5 cutoffs daily at 06:00Z, 2026-10-23 → 30. These are provisional: **G36 OPEN** in `fixtures/SPEC-GAPS.md`.
- **`.github/workflows/gate2.yml`:** manual dispatch on the self-hosted Mac runner. It rsyncs the VM fetcher root (never deleting), then runs `gate2.sh`.
- **Refactor (no behaviour change):** `gate1_evidence.py`'s checks.tsv reading, registry hours, commit and CI details are now functions, shared with `gate2_evidence.py`.

**Proof:** `./check.sh` passes; the new tests are `test_fetch_log_check.py` and `test_gate2_evidence.py`, plus a manifest case in `test_archive_input.py`. The dry run on the first 9 real hours passes all 9 checks (`BENCHMARKS.md`); evidence refused outside CI, as designed.
