# undercurrent

A verified GH Archive event pipeline. It turns GitHub's public event stream (hourly `.json.gz` files) into a canonical, deduplicated event table and a set of metrics. Correctness is proved, not assumed: two independently written implementations must agree exactly, and the output is reconciled against Google's BigQuery copy of the same source.

**Status: Gate 1 passed** on September 2026 (720 hours, 54.66M events), with evidence generated in CI: [`evidence/gate1.json`](evidence/gate1.json), run [38821187454](https://github.com/stevenrocca3/undercurrent/actions/runs/38821187454). Measured results: [`BENCHMARKS.md`](BENCHMARKS.md).

## How it is verified

| | What | Where |
|---|---|---|
| Spec | Event semantics, quarantine rules, deduplication, time model, output contract, gate criteria. Authoritative. | [`01-event-semantics.md`](01-event-semantics.md) |
| Fixtures | 27 hand-built cases (F01–F27) with expected outputs written from the spec | [`fixtures/`](fixtures/) |
| Pipeline | The product: parallel ingest into DuckDB, batch and replay modes | [`pipeline/`](pipeline/) |
| Reference | A ~350-line single-file calculation of the same outputs | [`reference/`](reference/) |
| Comparison | Exact equality of the R1–R7 output CSVs, no tolerance | [`tools/compare_outputs.py`](tools/compare_outputs.py) |
| Source reconciliation | Against BigQuery `githubarchive`, 0.1% tolerance, every outlier categorized | [`tools/reconcile.py`](tools/reconcile.py), [`tools/bigquery/`](tools/bigquery/) |
| Gate 1 evidence | CI-only run of every check, writes `evidence/gate1.json` | [`.github/workflows/gate1.yml`](.github/workflows/gate1.yml), [`tools/gate1.sh`](tools/gate1.sh) |

The pipeline and the reference are written by different agents, and neither reads the other's code (spec §6). The fixtures come from a third. Agreement between them is evidence because they share only the spec.

## Run the checks

```
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # once
./check.sh
```

`check.sh` runs the tool tests, then the reference on every fixture compared with `fixtures/*/expected/`, then the pipeline's tests, then the pipeline on every fixture compared the same way. Exit 0 means all pass. Set `PYTHON` to use another interpreter, as CI does ([`check.yml`](.github/workflows/check.yml), on every push).

Run either implementation on real data:

```
.venv/bin/python reference/reference.py run INPUT_DIR 2026-09-01T00:00:00Z 2026-09-30T23:00:00Z OUT_DIR --cutoff 2026-09-08T00:00:00Z
.venv/bin/python -m pipeline run INPUT_DIR 2026-09-01T00:00:00Z 2026-09-30T23:00:00Z OUT_DIR --cutoff 2026-09-08T00:00:00Z [--replay]
.venv/bin/python tools/compare_outputs.py dirs REFERENCE_OUT PIPELINE_OUT
```

## Gate 1 run (CI)

It needs a self-hosted runner, because a month is 19 GB of gzip plus working space. The runner also needs Python 3.13 and an authenticated `bq` (Google Cloud SDK in `~/google-cloud-sdk`; the BigQuery sandbox is enough, with 75 GB scanned per run). Start it from Actions → **gate1** → Run workflow, with the lid open and the charger connected. It takes about 55 minutes. The evidence comes out as the `gate1-evidence` artifact. The window and cutoffs live in [`tools/gate1_config.json`](tools/gate1_config.json).
